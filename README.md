# How to write it

Phone lookup page for Japanese course words: type romaji, kana, kanji or English and watch the stroke order of every character.

Data: stroke order from [KanjiVG](https://kanjivg.tagaini.net/) (Ulrich Apel, CC BY-SA 3.0); kanji readings and meanings from [KANJIDIC2](https://www.edrdg.org/) (EDRDG, CC BY-SA 4.0). The stroke files in `data/s/` are derived from KanjiVG and shared under CC BY-SA 3.0.
